TRAKTOR STEM PACKAGER — LOSSLESS LINKED TEST

This is an experimental test build. Do not share it publicly yet.

This app does not create or separate stems. Start with four stems you already
created or received, plus the matching stereo master.

Before testing:
1. Confirm the app title bar says v0.6.0-beta.22, then select
   “Lossless Traktor Installation.”
2. Choose the collection.nml used by that Traktor installation.
3. Choose the Stems folder configured in Traktor Pro 4 Preferences.
4. Start by adding the original master in the Master slot. You may add the four
   stems now, individually or with Import Folder, or add them later. The app
   checks Traktor automatically. If the master is already analyzed, import is
   skipped. Otherwise choose OPEN TRAKTOR & SHOW MASTER. Finder brings the exact
   file forward. Drag it into Traktor's Track Collection, not onto a deck, and
   let analysis finish. SHOW MASTER IN FINDER remains available if needed.
5. Add the four matching stems. This test build accepts
   uncompressed PCM WAV/AIFF at 16-bit/44.1 kHz or 24-bit/48 kHz.
   You can also choose IMPORT FOLDER, review the proposed assignments, drag
   files between slots to correct them, and choose ACCEPT ASSIGNMENTS.
   Test both manual file entry and Import Folder. In either path, ACCEPTED must
   be followed by an enabled orange next-action button.
6. Follow the orange next-action button. When Traktor must save its analysis,
   the app asks Traktor to close, verifies the latest saved collection and ID,
   installs the stems only if the master is still present, and reopens Traktor.
   If the master was deleted during the current Traktor session, the app stops,
   highlights it in Finder, and tells you to import and analyze it again. If
   Traktor does not close after the app's normal quit request, bring Traktor
   forward and press Command-Q. No Automation permission is required; the app
   detects the closure and continues automatically.
7. In Traktor, load the ORIGINAL master track. Do not import the hashed .stem.mp4 directly.
8. Confirm Open Traktor / Bring Traktor Forward remains available in the header
   without replacing or competing with the orange next workflow action.
9. In Traktor, unpair the saved Stem file from the master and save or close
   Traktor. Confirm the app reports that the master is analyzed but no longer
   linked, while separately recognizing whether the old Stem file still exists.

The app creates a timestamped backup of collection.nml before changing it. If a
linked Stem file already exists, the app asks before replacing it and keeps the
old file as a timestamped .bak safety backup. The .bak is not an active duplicate.
Before installing, it decodes all five packaged ALAC streams and requires their
PCM SHA-256 hashes to match the five source files exactly.

If Traktor is still open after analyzing the master, the analysis may not yet
be written to collection.nml. Choose the orange CLOSE TRAKTOR action. The app
will close Traktor, detect the saved collection, recheck the track ID, install,
and reopen Traktor without restarting the process.

For this test, confirm:
• The linked-stems icon appears beside the original track.
• The original track loads as a Stem Deck.
• Each of the four stems plays cleanly without noise, crackles, or pops.
• Playback remains clean near the end of the track.

ALAC linked stems are experimental in Traktor Pro 4. During testing, confirm
that playback remains clean through the end of every track.
